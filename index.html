📌 Thread States (Automated Email Detection)

📝 Not Contacted
Target identified. Research proposal or introductory inquiry not yet sent.
⏳ Awaiting Reply
Outreach email sent. Awaiting professor's first response (< 14 days elapsed).
👻 Ignored
14+ days passed with zero response. Professor is flagged as unresponsive.
💬 Replied
Professor responded to the conversation thread. Active dialogue initiated.
🤖 Automated Reply
Out-of-office autoreply or server autoresponder detected.

💬 Reply Statuses (Academic Outcome & Next Action)

🚨 Action Required
Professor replied! Ball is in your court to review, answer questions, or submit proposals.
📤 Awaiting Follow-up
You answered professor's questions or sent materials; currently awaiting their next reply.
✅ Accepted
Professor issued formal acceptance or agreed to supervise under MEXT!
❌ Rejected
Professor declined supervision (e.g. lab capacity full, retiring, research mismatch).
👻 Ghosted
Dialogue started, but professor went silent. Follow-up was sent, and 7+ more days passed without word.
➖ No Reply
Default state for professors who have not yet responded to outreach.

📊 Intelligent Hierarchical Sorting

The main tracker table organizes professors using a strict 6-tier priority hierarchy (most recent contact on top within each tier):
  • Priority 1: Replied (Action Required) — Pinned to the very top so you never miss an urgent reply or 7-day reminder.
  • Priority 2: Replied (Awaiting Follow-up) — Active conversations where you sent the last reply and are awaiting professor's response.
  • Priority 3: Replied (All Others) — Completed academic outcomes (Accepted, Rejected, Ghosted).
  • Priority 4: Awaiting Reply — Initial outreach sent (< 14 days), awaiting first response.
  • Priority 5: Ignored & Others — 14+ days silence or automated replies.
  • Priority 6: Not Contacted — Target identified, proposal not yet sent.

🛠️ Connect Your Own Google Sheet & Gmail Pipeline

Ready to track your personal professors? Deploy a private Google Sheet backend with Apps Script in ~3 minutes.
Step-by-step roadmap: Create Google Sheet with 10 columns → Add professor data → Open Extensions > Apps Script → Paste backend script → Set your Gmail → Deploy as Web App → Paste Web App URL in API Settings.

🛠️ Google Sheet & Apps Script Setup Guide

Deploy your private backend pipeline to track professors and sync live Gmail data
1️⃣ Create Google Sheet & Set Columns
Open sheets.new to create a new spreadsheet (e.g. named MEXT_Tracker). In Row 1 (Columns A through J), paste these exact 10 column headers:
ProfessorName * University Email * ResearchInterest Linked_Email Email_Logs Last_Contact Thread_State Notes Reply_Status
💡 Tip: Clicking the "Copy 10 Headers" button copies tab-separated values. In your Google Sheet, select cell A1 and press Ctrl+V to populate all 10 columns instantly!
2️⃣ Add Professor Records
Enter your target professors directly into the Google Sheet rows (at minimum: ProfessorName, University, and Email). Or, once connected, you can add and edit professors inside this web app using the ➕ Add Professor or 📥 Import (Excel) buttons!
3️⃣ Open Apps Script in Google Sheet
In your Google Sheet top menu, navigate to:
Extensions ➔ Apps Script
4️⃣ Paste the Backend Script (MEXT_Tracker.gs)
In the Apps Script editor, open Code.gs, clear any existing code, and paste the backend automation script. Click the 📋 Copy Script Code button above to copy the complete verified script to your clipboard.
5️⃣ Update Configuration Variables & Save
Near the top of the script (lines 8–10), replace the placeholders with your actual Google Sheet URL and Gmail address: 
var MEXT_TRACKER_SHEET_URL  = "https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit";
var MEXT_TRACKER_SHEET_NAME = "Sheet1";
var MEXT_TRACKER_USER_EMAIL = "your.email@gmail.com";
Click the 💾 Save icon (or press Ctrl + S).
6️⃣ Run & Grant Google Authorization Permissions
In the Apps Script top toolbar, select doGet or syncMextEmailsFromSheet in the function dropdown and click ▷ Run.
Google Permission Sequence:
  1. Click Review Permissions in the dialog.
  2. Select your Google account.
  3. Click Advanced (small text at lower-left).
  4. Click Go to MEXT_Tracker (unsafe).
  5. Click Allow to grant Sheet and Gmail search access to your own private script.
7️⃣ Deploy as Web App
In the top-right corner of Apps Script:
1. Click the blue Deploy button ➔ New deployment.
2. Click the gear icon (⚙️) next to Select type and select Web app.
3. Set Description: MEXT Tracker API.
4. Set Execute as: Me (your.email@gmail.com).
5. Set Who has access: Anyone (Crucial: allows this web tracker to sync data smoothly without Google login redirects).
6. Click Deploy.
8️⃣ Copy Web App URL & Connect in Tracker
1. Google will display your Web app URL (ending in /exec). Click Copy.
2. In this tracker app, click 🔑 API Settings in the action toolbar.
3. Paste your Web App URL and click Save.
4. Click 🔄 Sync from Gmail to test live communication with your Google Sheet! 🎉
